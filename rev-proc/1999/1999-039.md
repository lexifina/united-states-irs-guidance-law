SECTION 5. APPLICATION FOR THE FORM 941 e-file PROGRAM
.05 On-Line Filer. An On-Line Filer is a taxpayer that electronically files a Form 941 through a Transmitter using a personal computer, modem, and commercial tax preparation software.
The Form 941 e-file Program accepts electronically filed Forms 941 that are current returns, late returns for the current year, and returns for any quarter in the previous year. The Form 941 e-file Program will not accept the electronic filing of amended returns, corrected returns, or returns containing attachments other than Schedule B. A violation of these restrictions will cause a Processing Interruption (as defined in section 4.07 of this revenue procedure).
