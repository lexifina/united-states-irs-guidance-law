Section 3406.—Backup Withholding
See Rev. Proc. 2003–37, page 950.
SUMMARY: This document contains final regulations relating to backup withholding. These regulations clarify the method of determining whether the payor has received two notices that a payee’s taxpayer identification number (TIN) is incorrect. If a payor receives two or more such notices with respect to the same account during a three-year period, the payor must begin backup withholding unless the payee provides verification of its correct TIN pursuant to the regulations. This document also contains regulations which clarify when an information return filer must solicit a payee’s TIN following the receipt of a penalty notice.
26 CFR 31.3406(d)–5: Backup withholding when the Service or a broker notifies the payor to withhold because the payee’s taxpayer identification number is incorrect.
