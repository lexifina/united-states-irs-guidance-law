# Announcement 2010-58

Deletions From Cumulative List of Organizations Contributions to Which are Deductible Under Section 170 of the Code; Correction

This document contains a correction to Announcement 2010-55, 2010-37 I.R.B. 346, which contained an incorrect date within the document. The date incorrectly read: “September 7”.
The date should have read: “September 13, 2010”.
