# Announcement 2012-9

Deletions From Cumulative List of Organizations Contributions to Which are Deductible Under Section 170 of the Code; Correction

This document contains a correction to Announcement 2011-63, 2011-41 I.R.B. 503, which contained an incorrect name. The taxpayer name incorrectly read: “Allied Veterans Allied Veterans of the World Inc. & Affiliates.”
The taxpayer name should have read: “Allied Veterans of the World Inc. & Affiliates Post #24 Inc.”
